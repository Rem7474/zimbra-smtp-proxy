Zimbra SMTP Proxy

Passerelle SMTP locale pour Thunderbird qui envoie vos mails via l'API SOAP de Zimbra quand le SMTP du serveur n'est pas accessible.

Téléchargements

Installeur

Installation par utilisateur, sans droits administrateur. Non signé : Windows SmartScreen demande une confirmation au premier lancement (« Informations complémentaires » → « Exécuter quand même »).

Exécutable seul

Sans installation : lancez zimbra-smtp-proxy.exe depuis n'importe quel dossier. Les sommes SHA-256 et l'attestation de build sont jointes à chaque version.

ZimbraAuthRequest, upload, SendMsgRequest
  • Le message est transmis tel que Thunderbird l'a écrit : pièces jointes, HTML, Cc, Cci et fils de discussion sont conservés.
  • La passerelle écoute uniquement sur 127.0.0.1 : aucune autre machine du réseau ne peut s'en servir.
  • Le mot de passe n'est jamais enregistré. Il sert à ouvrir une session Zimbra dont le jeton reste en mémoire le temps de l'envoi.

Zimbra est testé au démarrage puis toutes les 5 minutes. Une notification signale la perte et le retour de la connexion. Le sous-menu Paramètres contient l'URL Zimbra, le port d'écoute et le lancement à l'ouverture de session.

Compiler depuis les sources

Prérequis : Go (version indiquée dans go.mod) et Inno Setup 6. Le script lance les tests, génère les icônes, compile l'exe puis l'installeur dans dist/.

git clone https://github.com/Rem7474/zimbra-smtp-proxy.git
cd zimbra-smtp-proxy
.\build.ps1 -Version 1.0.0          # Windows (PowerShell)
./build.sh 1.0.0                    # Linux, macOS, Git Bash (Inno Setup via Docker)
